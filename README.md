# G3 Architects

A responsive architecture and business website built with HTML and CSS. The project focuses on a professional multi-section layout, feature presentation, and responsive visual design.

## Tech Stack

- HTML5
- CSS3
- Responsive Web Design

## Highlights

- Professional navigation and hero section
- Feature-focused content layout
- Team and project imagery
- Responsive sections
- Clean CSS-based styling

## Getting Started

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/mdjihad-dev/office-website.git
cd office-website
```

## Project Focus

This project helped me practice building a complete business landing page from a visual design, with attention to spacing, layout, typography, and responsive behavior.
